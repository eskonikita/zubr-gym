## Правила продолжения

Текущий запрос: анализ и подготовка, затем работа по одной странице. Не запускать автоматически разработку всех страниц из приложенного общего задания. Делать один образец каждого согласованного типа, а повторяющиеся страницы впоследствии наполнять в MODX.

Приоритет текущих визуальных материалов — две присланные композиции. Существующий `.superdesign/design-system.md` — прежняя концепция с другой палитрой, типографикой и мобильным порядком. Она сохранена как история и не является источником текущих токенов. Здесь нет нового проекта или генерации в Superdesign.

`public/`, оригинал `reference/bronxgym/` и существующие материалы `.superdesign/` на этом этапе не изменялись. Ничего из выгрузки не удалялось.

Следующий практический этап — общий каркас и главная, после команды пользователя. Начать с чистой HTML/CSS/JS-вёрстки выбранного образца, не накладывать новые блоки на гидратируемый React оригинала.
