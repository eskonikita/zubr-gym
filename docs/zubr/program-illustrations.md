# Иллюстрации программ

Главная: `public/index.html` и её синхронная копия `public/zubr/home.html`.

В каждой информационной карточке подготовлен отдельный контейнер `.group-panel__art`:

| Программа | Контейнер |
| --- | --- |
| Взрослые | `[data-program-art="adults"]` |
| Подростки | `[data-program-art="teens"]` |
| Дети | `[data-program-art="kids"]` |
| Персональные тренировки | `[data-program-art="personal"]` |

Вставить внутрь соответствующего контейнера изображение:

```html
<img class="group-panel__image" src="/zubr/images/имя-файла.webp"
     width="600" height="800" alt="" loading="lazy">
```

Размеры `width` и `height` заменить фактическими размерами файла. Подходят SVG, WebP или PNG с прозрачным фоном, с чёрными, белыми и красными силуэтами в стилистике зубров из блока направлений. Вёрстка использует `object-fit: contain`, без обрезки и фильтров. Контейнер декоративный, название программы уже есть рядом.

Подключены четыре предоставленные пользователем иллюстрации из `public/zubr/images/`: `group-adults-800.webp` для взрослых, `group-teens-800.webp` для подростков, `group-kids-800.webp` для детей и `group-personal-800.webp` для персональных тренировок. На телефоне изображение располагается под текстом. При переключении программы показывается её собственная иллюстрация. Все четыре панели участвуют в расчёте общей высоты, неактивные панели скрыты визуально и для средств доступности и исключены из фокуса через `inert`.
